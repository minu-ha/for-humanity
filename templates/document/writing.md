문서 한 장 = Markdown 파일 하나. 머리말, 절, 가름, 본문 부품의 작성 기준.

## 한눈에

```markdown
---
name: Guide
label: 사용 안내
group: 시작
---

문서의 범위와 핵심.

## 한눈에

::part[시작]

## 설치
### 요구 사항
```

문서 폴더에는 Markdown과 선택 설정 파일. 루트 `README.md`, `node_modules`, `dist`는 문서 대상에서 제외.
하위 폴더도 지원. `.mdx`는 Markdown으로 처리 · JSX 실행 미지원.

::part[형식]

## 머리말

| Key | Use | Required |
| --- | --- | --- |
| `name` | 제목 · 목록 · 카드 · 첫 글자 표지 | 필수 · 비어 있지 않은 이름 |
| `label` | 한글 이름 · 카드 설명 · 목록 툴팁 | 필수 |
| `group` | 카드 묶음 · 문서 머리 라벨 | 필수 |
| `type` | `document` / `blueprint` | 기본 `document` |

문서 이름의 첫 글자는 대소문자 구분 없이 고유. `blueprint` 전용 표현은 아직 미구현.
파일 경로는 확장자를 뺀 소문자 id로 사용. `.md`와 `.mdx`, 대소문자만 다른 경로의 id 중복 금지.
빈 경로와 예약 문자 `#`, `?`, `%`, `*`, `:`, `\`는 사용 불가. 첫 경로 `/_fh/`는 킷 자원 전용.
`.`·`..`·`index.html` 경로 조각, 제어문자, 첫 경로 `/favicon.svg/`는 정적 출력과 충돌하므로 사용 불가.

## 절과 가름

- `##` → 절 번호 `00`, `01`, `02`
- `###` → 소제목 번호 `01.A`, `01.B` · 절당 최대 26개
- 첫 절 앞의 글 → 문서 머리
- `::part[이름]` → 본문 가름 · 목차 묶음
- 제목 id → GitHub 방식 · 같은 제목은 `-1`, `-2` 접미사

### 문서 링크

```markdown
[설정](settings.md)
[상태 표지](settings.md#상태-표지)
```

상대 Markdown 링크 → 사이트 문서 URL. GitHub에서도 같은 파일로 이동.
외부 URL, 절대 URL, 같은 문서의 `#절`은 원문 유지.

::part[본문]

## 본문 부품

| Source | Result |
| --- | --- |
| GFM 표 | 넓은 표의 내부 가로 스크롤 |
| 언어 지정 코드 블록 | Shiki 코드 강조 |
| 인라인 색 값 `#e80030` | 색 칩 |
| 설정의 상태 문구 | 상태 표지 |

상태 문구는 [Settings](settings.md#상태-표지)에서 변경.
원시 HTML은 그대로 반영되는 작성 형식. 외부 콘텐츠의 실행·격리 환경은 제공하지 않음.

## 글 기준

- 한 줄 한 사실
- 제목과 요약은 명사구 중심
- 경위보다 현재 계약·결정·제약
- 식별자와 값은 코드, 절차는 목록, 비교는 표
- 실제 지원 범위와 미구현 범위 구분
