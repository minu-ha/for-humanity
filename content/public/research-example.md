가상 독서 앱에서 조회 오류가 빈 목록처럼 표시되는 문제를 조사하는 견본입니다.
아래 관찰·파일·검증 결과는 모두 가짜 데이터이며 for-humanity의 실제 결함이나 실행 결과가 아닙니다.

## Question

조회가 실패했는데 사용자가 “저장한 책이 없다”고 읽게 되는가?
확인 범위는 책 목록 화면의 오류·빈 결과 분기입니다.

## Observations

| 조건 | 관찰 | 근거의 종류 |
| --- | --- | --- |
| 정상 응답 `books: []` | 빈 목록 안내 | 예시 응답 |
| 조회 오류 | 빈 목록 안내로 대체 | 가상 코드의 분기 |
| 네트워크 복구 | 재조회하면 목록 표시 | 가상 로컬 실행 기록 |

## Decision

오류는 실패 안내와 다시 시도할 동작을 표시합니다. 정상적인 빈 결과와 구분합니다.
표시 문구와 실제 재시도 정책은 프로젝트의 제품 결정입니다.

:::note[Remaining question]
연결이 끊긴 상태에서 이전 목록을 보여줄지는 아직 정하지 않았습니다.
추천은 이전 목록과 오류 안내를 함께 표시하는 것이지만, 채택한 결정은 아닙니다.
:::

## Checks

- [x] 가상 분기 검토: 실패와 빈 결과를 분리
- [x] 가상 로컬 검증: 오류 안내와 다시 시도 표시
- [ ] 실제 운영 환경의 네트워크 단절 확인
- [ ] 스크린 리더로 오류 안내 확인

체크 표지는 이 가상 문서의 기록입니다. 실제 검증을 수행했다는 증거가 아닙니다.
예시 문서는 주장·관찰·한계·남은 확인을 분리하는 작성 방법을 보여줍니다.
